# Use cases

## 1) POS end-of-day processing

Evaluate qualification and pricing/discount rules across large transaction sets.
Use pass grouping and deterministic replay for auditing and correction workflows.

## 2) Streaming authorization decisions

Apply decision logic to fast event streams and produce explainable outputs with reason codes.

## 3) Settlement replay and correction

Re-run historical rule evaluations against pinned run contexts to verify consistency and produce corrected outputs.

## 4) Underwriting rules

Apply rule sets with controlled execution groups to support explainable, deterministic decisions.

## 5) Rule simulation before promotion

Evaluate draft rules against sample facts, inspect fired outputs, and iterate safely before operational rollout.
